Coloca aquí las fotografías/capturas que quieras mostrar en la galería.
Formatos recomendados: .jpg, .jpeg, .png, .webp, .gif

Después edita docs/kernel/gallery.json y agrega una entrada por imagen, por ejemplo:
[
  {
    "src": "gallery/mi-foto.jpg",
    "title": "Título",
    "desc": "Descripción breve"
  }
]

La galería del dashboard cargará automáticamente este archivo.
